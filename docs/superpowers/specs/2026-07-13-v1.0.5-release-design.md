# CodexQ 1.0.5 Release Design

## Goal

Publish the verified weekly-only quota compatibility changes as GitHub Release `v1.0.5` for Apple Silicon and Intel Macs.

## Release contents

- Accept a missing 5-hour quota window while preserving weekly quota refresh.
- Display the missing 5-hour window as a gray segmented bar labeled `无限制`.
- Keep the 5-hour and weekly bars aligned.
- Preserve existing behavior when both quota windows are present.

## Distribution

- Push the release commit directly to `origin/main` as explicitly requested.
- Build `CodexQ-1.0.5-arm64.zip` and `CodexQ-1.0.5-x86_64.zip` sequentially.
- Verify archive structure, executable architecture, and app signature.
- Create GitHub Release `v1.0.5` targeting `main` with both archives and Chinese release notes.
- State that packages are ad-hoc signed and not notarized.

## Documentation

Update `README.md` and `README.en.md` to use version `1.0.5` in download and packaging examples and document weekly-only quota compatibility.
