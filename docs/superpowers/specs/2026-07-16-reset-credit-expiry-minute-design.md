# 限额重置到期时间精确到分钟设计

## 目标

将限额重置明细的到期文案从“将于 M/d 到期”改为“将于 M/d HH:mm 到期”，使用本机时区并精确到分钟。

## 范围

- 保留现有 `expiresAt` 数据解析和限额重置界面布局。
- 仅调整 `ResetCreditPresentation` 的日期格式，以及对应的展示测试。
- 缺少到期时间时仍显示“无到期时间”。
- 不修改刷新链路、缓存结构、重置次数逻辑或其他额度时间格式。

## 数据流与展示规则

后端提供的 Unix 时间戳继续转换为 `Date`，再由 `ResetCreditPresentation` 使用传入或本机的时区格式化。格式固定为 `M/d HH:mm`，例如“将于 7/27 07:53 到期”。

## 验证

- 单元测试固定使用 UTC+8，验证日期和分钟均正确输出。
- 保留无到期时间的现有测试。
- 运行相关测试及完整测试，确认没有影响其他额度展示。
