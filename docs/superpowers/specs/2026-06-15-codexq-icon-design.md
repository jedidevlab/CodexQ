# CodexQ 图标设计

## 目标

设计一个具有辨识度的 CodexQ 标志，同时适用于 macOS App 图标和菜单栏模板图标。

## 标志造型

使用开放式圆环构成粗体几何 `Q`：

- 圆环右上方保留一个明确的缺口，用来暗示额度进度。
- 右下方延伸出一条短尾，使图形能够清晰识别为 `Q`。
- 图形缩小到 16 px 时仍须保持可辨识。
- 避免内部细节、纤细线条、文字、阴影和装饰性符号。

## App 图标

- 画布尺寸：1024 x 1024 px。
- 背景：符合 macOS 风格的中性深灰色圆角方形。
- 前景：纯白色开放式圆环 `Q`。
- 不使用品牌色；标志本身不使用渐变；圆角方形内部不使用透明区域。
- 从 1024 px 母版生成 `.icns` 所需的各档尺寸。

## 菜单栏图标

- 母版：512 x 512 px、带 Alpha 通道的 PNG。
- 前景像素：纯白色，边缘通过 Alpha 通道抗锯齿。
- 背景：完全透明。
- 将生成的 `NSImage` 设为模板图像，由 macOS 根据深色或浅色菜单栏控制最终显示颜色。
- 在所有额度状态下始终显示完整标志，不根据剩余额度对图标进行裁切、填充、淡化或其他变形。
- 验证图标在 16、18 和 32 px 下的可辨识度。

## 项目接入

- App 图标与菜单栏图标使用不同资源，因为两者的背景要求不同。
- 更新 App 打包脚本，从 App 图标母版生成 `AppIcon.icns`。
- 从 Swift Package 资源包中加载菜单栏 PNG。
- 额度信息继续通过工具提示和弹窗展示，图标本身保持静态。

## 验证

- 确认菜单栏资源包含 Alpha 通道，并且所有可见像素均不带彩色。
- 分别渲染 16、18 和 32 px 预览，目视检查 `Q` 的辨识度。
- 构建 Swift Package 并打包 App。
- 启动 App，确认进程能够持续正常运行。
