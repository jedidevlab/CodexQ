# CodexQ 1.0.5 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish CodexQ 1.0.5 to GitHub with verified arm64 and x86_64 packages.

**Architecture:** Documentation and release metadata are committed to `main` before packaging. Both architectures are built sequentially with the existing release script, verified independently, and uploaded to one GitHub Release.

**Tech Stack:** SwiftPM, shell release script, Git, GitHub CLI.

## Global Constraints

- Version and tag are `1.0.5` and `v1.0.5`.
- Assets are `CodexQ-1.0.5-arm64.zip` and `CodexQ-1.0.5-x86_64.zip`.
- Packages remain ad-hoc signed and not notarized.
- Push directly to `origin/main` as explicitly requested.
